# Customer - Customizations & Logic

## 1. Custom Fields & Data Mapping
* **Customer Category:** Custom field `cen_customer_category` created as a Select dropdown (Options: VIP, CORE, STANDARD). Default set to STANDARD. 
* **Quick Entry Visibility:** This field is enabled for Quick Entry (`allow_in_quick_entry: 1`) so it immediately appears in the modal popup when creating a new Customer from an Opportunity, Quotation, or Sales Order.
